# User Stories

1. As a librarian, I want to add a book so that it appears in the library list.
2. As a librarian, I want to add a magazine so that different item types can be managed.
3. As a user, I want to see all items sorted by title so that I can find an item easily.
4. As a user, I want to borrow an available item so that I can take it from the library.
5. As a user, I want the program to reject borrowing an already borrowed item.
6. As a user, I want to return an item so that it becomes available again.
7. As a librarian, I want the program to save and reload items so that data remains after closing the application.
